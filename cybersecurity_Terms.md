- **Malware** is a program or software that is designed to damage, disrupt, or gain unauthorized access to a computer.

- **Exploits** are programs or code that take advantage of the vulnerability or flaw in the application or system.

- A **payload** is a malicious code that the attacker runs on the system.

- **Email harvesting** is the process of obtaining email addresses from public, paid, or free services.
- **phishing attack** is a type of social-engineering attack used to steal sensitive data, including login credentials and credit card numbers.
